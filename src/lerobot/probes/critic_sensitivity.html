What is being differentiated?

Robot state is measured at its discrete value embeddings or projected continuous-state embedding, according to the checkpoint. State and categorical metadata gradients are with respect to their embeddings, not joint angles or integer label IDs. Images are measured at the frozen encoder’s output. Padding and the learned value token are excluded.

The depth component includes consumed projected depth features. Missing-depth null tokens and unfilled placeholders are excluded. Continuous state requires the critic’s own state projection; older checkpoints use discrete state-value embeddings.

Large gradients can occur where an accurate critic responds sharply. This view does not infer failure-prone execution from critic prediction error. Norms depend on representation scale and token count; compare frames within the same subtask and input group.
