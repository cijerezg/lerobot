Prompt-token gradients
Quantities and coverage

The default gradient covers RGB image features, state-value embeddings, and real depth features when consumed, at the input to critic fusion. Fixed prompt wording, task/subtask text, metadata and missing-modality placeholders are excluded. The critic retains its original conditioning. Image-only, state-only and depth-only norms remain selectable. These are embedding derivatives, not raw-pixel, metric-depth or physical joint-coordinate derivatives. Representation scale and input size affect the norm; gradient magnitude alone is not directly comparable across architectures.

ΔV = V(next frame) − V(current frame), one action chunk apart with identical task, subtask, metadata and cameras, without crossing a critic terminal. Raw advantage = clip(reward + γ(1 − terminal)V(next frame), value support) − V(current frame). Terminal advantage needs no next value. Missing matching forwards are marked unavailable. V and gradients are from the saved gradient-enabled forwards.

Time remaining and segment progress use critic terminals, with release folded into the preceding move. Colour-free subtask removes common colour words for display only. Histogram counts weight every sampled frame equally. Conditional density normalizes each gradient column independently; hover shows its sample count.
